# Echo Escape

[PRD](PRD.md)와 [사전 기획서](PRE_PRD.md)를 바탕으로 개발하는 분신 퍼즐 게임이다. Python 3.13과 pico2d 1.5.1 환경에서 실행한다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

`Enter`로 시작한다. `←`/`→`로 움직이고 `A` 또는 `S`로 기본 공격을 한다. `C`로 분신을 직접 조작해 이동과 대기를 녹화하고, 다시 `C`를 누르면 본체 조작과 분신 재현이 시작된다. `Backspace`로 녹화를 취소하고 `R`로 맵을 초기화한다. `Esc`로 종료한다.

## 1주차 · 기본 조작과 분신 재현

- 방향키 이동, 벽 충돌, 기본 공격 입력과 애니메이션
- 녹화 중 본체와 세계 시간 정지
- 녹화 시작점에서 분신이 이동과 대기를 한 번 재현

## 2주차 · 분신 교체와 발판·문

- 기존 분신은 새 녹화 중 정지하고 새 재현을 시작하면 교체된다. 분신은 재현 완료 또는 한 번의 피격으로 사라진다.
- 1층 연습 맵에서 분신을 A 발판까지 이동시켜 약 4초 기다리게 녹화한다. 재현을 시작한 뒤 본체로 A 문을 통과한다.
- 녹화 중에는 발판과 문이 멈춘다. 재현 분신이 발판을 떠나거나 소멸하면 문은 짧은 유예 후 닫힌다. 문을 건너는 중인 본체나 분신은 문이 닫히기 전에 빠져나갈 수 있다.
- 피격 규칙은 `World.hit_echo()`로 검증할 수 있다. 몬스터의 추적과 공격 연결은 이후 주차 범위다.
