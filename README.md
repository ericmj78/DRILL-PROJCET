# Echo Escape

녹화한 행동을 분신에게 맡기고 본체로 지하 감옥을 탈출하는 Python/pico2d 2D 액션 퍼즐. [기획 요구사항](PRD.md)과 [사전 기획](PRE_PRD.md)을 바탕으로 만든 플레이 가능한 초기 버전이다.

## 실행

`DRILL-PROJCET` 폴더에서 실행한다. Python 3.13과 pico2d 1.5.1로 확인했다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

| 키 | 동작 |
| --- | --- |
| 타이틀 메뉴 | 방향키와 `Enter` 또는 마우스 클릭으로 게임 시작, 스테이지 선택, 조작법, 설정(전체 화면/창 모드), 종료 |
| `Enter` | 다음 스테이지, 전체 완료 후 처음부터 |
| `←` / `→` | 현재 조작 대상 이동 |
| `↑` / `↓` | 사다리 가까이에서 층 이동 |
| `C` | 분신 녹화 시작 또는 녹화 종료 후 재현 |
| `A` / `S` | 본체의 기본 공격 |
| `Backspace` | 녹화 취소 |
| `B` | 보스방으로 바로 이동 (보스가 없는 스테이지에서는 다음 보스 스테이지) |
| `R` / `Esc` | 스테이지 재시작 / 타이틀 화면으로 (타이틀에서 `Esc`는 종료) |

발판과 문은 알파벳이 같은 것끼리 연결되어 있다. 분신은 녹화를 시작한 자리에서 출발하므로, 어디서 `C`를 누르느냐가 분신과 본체가 걷는 거리를 함께 정한다. 스테이지마다 분신 한 번에 녹화할 수 있는 시간이 다르며 화면 위 막대에 표시된다.

첫 스테이지의 `B` 발판은 `A` 문보다 앞에 있다. `A` 발판과 `A` 문 사이에서 녹화를 시작해 분신이 `A` 발판에서 잠깐 기다린 뒤 `B` 발판으로 옮겨 가 기다리게 한다. 본체는 `A` 문을 지나 적을 베며 `B` 문까지 달린다. 막히면 [test_stages.py](test_stages.py)의 `SOLUTIONS`에서 스테이지별 공략을 볼 수 있다.

뿔짐승, 돌 수호자, 마법 갑옷 경비도 공격해 처치할 수 있다. 분신으로 유인하거나 다른 층으로 돌아갈 수도 있다. 숨은 함정은 분신 가까이에서만 보이고, 보이는 동안에만 점프로 넘을 수 있다. 문 너머로 넘어간 뒤 뒤쪽 발판이 필요해지면 `R`로 다시 시작해야 하는 구간이 있다.

## 수정하는 곳

| 파일 | 바꿀 수 있는 내용 |
| --- | --- |
| `stages.py` | 스테이지 제목·힌트, 시작점, 출구, 발판과 문, 사다리, 적의 배치와 수치 |
| `world.py` | 분신 녹화·재현, 충돌, 버튼 상태, 전투와 적의 추적 |
| `view.py` / `assets/` | 화면 배치, 표시 문구와 이미지 |
| `monster_attack.py` / `player_attack.py` / `assets/attack_fx/` | 몬스터와 본체의 공격 자세, 타격 이펙트, 타이밍 |
| `boss_skills.py` | 보스 스킬의 종류, 예고·발동·빈틈 시간, 사거리, 피해 범위 |
| `animation.py` / `assets/walk_frames.json` | 걷기 속도에 따른 자세 전환과 스프라이트 영역 |
| `main.py` | 조작키와 게임 시작·재시작·다음 스테이지 처리 |

`Point(x, floor)`의 `floor=0`은 1층이다. `Stair(x, lower)`는 `lower` 층과 바로 윗층을 연결한다. `Gate(label, plate, door)`로 발판과 문을 연결한다. 파일을 수정했다면 `python main.py`로 다시 실행해 배치를 확인한다. 플레이 중에는 `R`로 현재 스테이지를 초기 배치에서 다시 시작할 수 있다.

녹화 상한은 스테이지의 `echo_seconds`(기본 9초)로 정한다. 본체 체력 3, 문 닫힘 유예 0.18초는 조정할 수 있는 초기값이다. 상한에 도달하면 자동으로 재현을 시작한다. 빈 기록과 녹화 취소는 기존 분신을 보존한다. 재현은 기록된 입력을 현재 지형에서 실행하므로, 녹화 때 열렸던 문이 닫혔다면 분신도 그 문에 막힌다.

스테이지를 고친 뒤에는 `python test_stages.py`를 실행한다. 화면 없이 스테이지마다 공략대로 깨지는지, 분신 없이 달리기만 해서는 못 깨는지 확인한다. 배치를 바꿨다면 같은 파일의 공략도 함께 고친다.

작업 브랜치는 `codex/echo-escape-game`이다. 저장소에서 `git switch codex/echo-escape-game`으로 돌아올 수 있다.
