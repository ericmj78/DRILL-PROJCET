# Echo Escape

녹화한 행동을 분신에게 맡기고 본체로 지하 감옥을 탈출하는 Python/pico2d 2D 액션 퍼즐. [기획 요구사항](PRD.md)과 [사전 기획](PRE_PRD.md)을 바탕으로 만든 플레이 가능한 초기 버전이다.

## 실행

`DRILL-PROJCET` 폴더에서 실행한다. Python 3.13과 pico2d 1.5.1로 확인했다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

| 키 | 동작 |
| --- | --- |
| `Enter` | 시작, 다음 스테이지, 전체 완료 후 처음부터 |
| `←` / `→` | 현재 조작 대상 이동 |
| `↑` / `↓` | 사다리 가까이에서 층 이동 |
| `C` | 분신 녹화 시작 또는 녹화 종료 후 재현 |
| `A` / `S` | 본체의 기본 공격 |
| `Backspace` | 녹화 취소 |
| `R` / `Esc` | 스테이지 재시작 / 종료 |

첫 스테이지에서 `C`를 누르고 분신으로 `A` 발판까지 오른쪽으로 이동한다. 발판에서 약 4초 기다린 뒤 다시 `C`를 누르고 본체로 출구까지 이동한다. 발판과 문은 알파벳이 같은 것끼리 연결되어 있다. 2층에서는 분신이 아래층 발판을 유지하며 적을 유인하는 동안 본체가 윗길을 달린다. 3층에서는 `A` 문을 통과한 뒤 `B` 발판을 향해 새 기록을 만든다.

## 수정하는 곳

| 파일 | 바꿀 수 있는 내용 |
| --- | --- |
| `stages.py` | 스테이지 제목·힌트, 시작점, 출구, 발판과 문, 사다리, 적의 배치와 수치 |
| `world.py` | 분신 녹화·재현, 충돌, 버튼 상태, 전투와 적의 추적 |
| `view.py` / `assets/` | 화면 배치, 표시 문구와 이미지 |
| `main.py` | 조작키와 게임 시작·재시작·다음 스테이지 처리 |

`Point(x, floor)`의 `floor=0`은 1층이다. `Stair(x, lower)`는 `lower` 층과 바로 윗층을 연결한다. `Gate(label, plate, door)`로 발판과 문을 연결한다. 파일을 수정했다면 `python main.py`로 다시 실행해 배치를 확인한다. 플레이 중에는 `R`로 현재 스테이지를 초기 배치에서 다시 시작할 수 있다.

녹화 상한 9초, 본체 체력 3, 문 닫힘 유예 0.18초는 조정할 수 있는 초기값이다. 상한에 도달하면 자동으로 재현을 시작한다. 빈 기록과 녹화 취소는 기존 분신을 보존한다. 재현은 기록된 입력을 현재 지형에서 실행하므로, 녹화 때 열렸던 문이 닫혔다면 분신도 그 문에 막힌다.
