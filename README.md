## 게임 소개

자신의 이동과 대기 행동을 기록해 분신 한 명이 재현하도록 하고, 분신이 버튼을 유지하거나 몬스터를 유인하는 동안 본체가 다른 행동을 수행해 탈출하는 게임입니다.

- 분신은 최대 한 명이며 공격할 수 없습니다.
- 기록은 한 번 재현하며, 분신은 한 번 피격되거나 재현이 끝나면 사라집니다.
- 새로운 분신은 새 행동을 기록해야 하며, 소환 시 기존 분신과 교체됩니다.
- 한 화면의 1층 스테이지부터 시작해 2~3층으로 확장하는 방향입니다.
- 추가 아이디어는 핵심 기능을 완성한 후 후보부터 시험합니다.
