# 소리 후보 (GitHub에서 찾은 CC0 소리)

들어 보고 마음에 드는 파일을 알려 주면 게임 소리(`assets/sound`, `sound.py`)를 바꾼다.
게임에서는 아직 쓰지 않는다. 다 고른 뒤에는 이 폴더를 지워도 된다.

## 출처 (둘 다 CC0: 크레딧 없이 마음대로 써도 된다)
- 1~5번 폴더: [facebookincubator/Meta-open-sound](https://github.com/facebookincubator/Meta-open-sound) (Meta가 공개한 Oculus 오디오 팩)
- 6번 폴더: [Beatscribe/homebrew_vgm](https://github.com/Beatscribe/homebrew_vgm) (SNES 스타일 짧은 음악)

## 어디에 쓰면 좋을지
| 폴더 | 바꿀 수 있는 게임 소리 |
|---|---|
| 1_칼_휘두르기 | 베기(slash), 찌르기(thrust), 대시(dash). `WEAPSwrd_SwordClash`는 보스 공격을 막을 때 |
| 2_타격 | 적을 맞혔을 때(hit), 내가 맞았을 때(hurt), 돌진(charge) |
| 3_마법·보스스킬 | 해골 불꽃(skulls: `GOREBone_SkullCracking`), 그림자 손(hands: `DSGNImpt_ImpactCreepyReverb`), 잔향 기사 울음(`CREAMnstr_CreatureCreepyReverb`), 마녀 마법(`MAGSpel_MagicSpell`) |
| 4_레벨업 | 레벨업(level_up) |
| 5_착지·점프 | 착지 소리 (지금은 없음) |
| 6_보스등장·승리·게임오버 | 보스 등장(`boss_appears`), 보스 처치(`victory`), 패배(`game_over`), 스테이지 시작(`level_start`) |
